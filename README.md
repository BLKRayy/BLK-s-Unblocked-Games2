BLK Games (Unblocked)
BLK Games is a fully custom, dark‑neon, electric‑blue unblocked game hub designed for speed, polish, and a premium launcher‑style experience. It combines a modern UI, animated visuals, a particle‑based background, and a built‑in AI assistant to create a game site that feels like a real platform rather than a simple webpage.

Features
Dark‑Neon Electric Blue Theme  
A polished, modern interface inspired by premium game launchers, with glowing accents, smooth transitions, and a particle‑animated background.

Game Grid  
A responsive, animated grid of square game cards with hover glow, category filtering, search, favorites, and recently played.

Featured Games Row  
A dedicated section for top games marked as “featured,” displayed in a glowing horizontal row.

Game Viewer  
A neon‑framed iframe viewer with fullscreen mode, animated hints, and smooth transitions.

AI Mode (Copilot‑Style)  
A floating neon orb that opens a rounded‑rectangle AI panel. Students can ask questions, get explanations, summaries, and simple practice prompts.

Maintenance Mode  
An animated shutdown‑style overlay with pulsing neon effects, used to temporarily disable the site.

Announcements & Timer  
Admin‑controlled announcement bar and countdown timer displayed on the homepage.

Changelog Display  
A built‑in update log visible on the main page, editable from the admin panel.

Admin Control Center  
A full dashboard for managing games, announcements, timers, maintenance mode, changelog, and more.

LocalStorage‑Powered Editing  
All admin changes save instantly on the device without needing a backend.

Tech Stack
HTML5 for structure

CSS3 with animations, gradients, and neon effects

JavaScript for game loading, UI logic, AI mode, admin tools, and animations

LocalStorage for persistent data

JSON for game definitions

How It Works
The site loads games.json and merges it with any admin‑edited data stored locally.

The homepage displays featured games, the full grid, and the viewer.

The AI orb opens a modal where students can ask questions.

Admins can log in to manage everything from games to maintenance mode.

Maintenance mode overrides the entire UI with an animated overlay.

Project Goals
Deliver a polished, modern unblocked game experience

Provide a clean admin workflow for adding and managing games

Add educational tools (AI Mode) without cluttering the UI

Maintain a premium, animated, neon‑themed aesthetic
